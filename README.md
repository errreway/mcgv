# ignite-go

## Apache Ignite client for golang
This client is under active development and is not production ready.

### Road map
1. Develop "[Cache Configuration](https://ignite.apache.org/docs/latest/binary-client-protocol/cache-configuration)" methods (98% readiness)
2. Develop "[Key-Value Queries](https://ignite.apache.org/docs/latest/binary-client-protocol/key-value-queries)" methods (50% readiness)
3. Develop "Expiry Policy" support (100% readiness)
4. Develop connection failover (0% readiness)
5. Develop partition awareness (0% readiness)
6. Develop "[SQL, Scan and Index Queries](https://ignite.apache.org/docs/latest/binary-client-protocol/sql-and-scan-queries)" methods (0% readiness)
